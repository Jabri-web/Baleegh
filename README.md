---

## 📌 عن المشروع
هذا النظام يسمح لمدير الشبكة بالتحكم الكامل في أجهزة **ميكروتيك** خاصة هوتسبوتات `Al_Ankaboot` عبر **بوت تليجرام**، دون الحاجة لبروكسي أو واجهة ويب معقدة.

تم تصميم البوت ليكون **تفاعلياً بالأزرار 100%**، مناسب للاستخدام من الهاتف. 
والواجهة `index.html` للتوثيق والعرض فقط.

### مشكلة "فشل البروكسي" تم حلها
الكود القديم كان يعتمد على المتصفح للاتصال بالميكروتيك وهذا يفشل بسبب `CORS`.
الحل: البوت يتصل مباشرة من السيرفر للميكروتيك.

- ✅ **مراقبة سرعة Rx/Tx** لأي هوب
