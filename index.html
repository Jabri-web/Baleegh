⚙️ متطلبات التشغيل

لتشغيل البوت على السيرفر:

  • ✅ Python 3.10+
  • ✅ مكتبة routeros-api
  • ✅ python-telegram-bot
  • 🔌 منفذ API في الميكروتيك: 8728

📋 الأوامر المتاحة

/start - بدء التشغيل
IP user pass - تسجيل الدخول للميكروتيك
/hotspots - عرض الهوبات
/users - مستخدمي هوب معين
/disconnect - فصل مستخدم
/status - حالة النظام
/logout - تسجيل الخروج

🛠️ إعداد الميكروتيك

تأكد من تفعيل API:

/ip service enable api

يفضل تحديد عنوان IP السيرفر في القائمة البيضاء.

📖 دليل الاستخدام السريع

  1. تسجيل الدخول: اضغط "افتح البوت" وارسل: IP username password
  2. استعراض: بعد الاتصال اضغط "عرض الهوبات" لرؤية جميع نقاط الشبكة.
  3. التحكم: اختر الهوب المطلوب لعرض مستخدميه، أو إيقافه/تشغيله.
  4. الفصل: انسخ الـ .id من قائمة المستخدمين واستخدم زر "فصل".
