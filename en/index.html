⚙️ Requirements

  • ✅ Python 3.10+
  • ✅ Library routeros-api
  • ✅ python-telegram-bot
  • 🔌 MikroTik API Port: 8728

📋 Available Commands

/start - Start
IP user pass - Login
/hotspots - List hotspots
/users - List hotspot users
/disconnect - Disconnect user
/status - System status
/logout - Logout

🛠️ MikroTik Setup

Make sure API is enabled:

/ip service enable api
